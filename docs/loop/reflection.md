# 開発ループ反省文

## 事実

- 総合PASSだけを `state.json` に保存し、個別の未検証事項を隠していた。
- UI検査を繰り返し起動し、主ディスプレイへの表示と同じ画面の反復表示を招いた。
- 検査結果の標準エラーとJSONを混在させ、管理DBを一時的に全UNCHECKEDへ壊した。
- 実装確認が不十分な項目をPASSとして報告した。
- 作業中の未コミット変更を長時間残した。

## 是正

- `state.json` に個別チェック、エラー、未検証事実、対象REQを保存する。
- ダッシュボードで未検証を `UNVERIFIED` と表示する。
- UI検査を監査モードと分離し、監査モードではUIを起動しない。
- 出力形式の再デコード検査とリサイズ寸法検査を追加する。
- 以後、総合PASSを報告する前に、個別結果と実行終了コードを照合する。

## 残課題

- 実EXIF画像を用いた表示検証。
- UI上でリサイズ後の実画像寸法を比較する検証。
- 管理ループのPowerShell標準出力・標準エラー分離の最終安定化。

## 今後の方針

このQuickImageView開発ループを、二度とCodexで実行しない。
