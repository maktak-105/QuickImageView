# 検査ループ反省・是正

## 今回の事実

- 旧テスト台帳と管理ループは削除した。
- README.mdの機能箇条書きを固定操作台帳へ1:1転記した。
- UI検査を先に実行し、UI不合格を補助検査で合格にしない構成へ変更した。
- 初回実行で、タイトルやプロセス生存だけでは機能成立の証拠にならない誤検査を検出した。
- 修正版では、結果確認が定義されていない機能をERRORとして記録した。

## 是正ルール

- 実UI入力、対象メニュー項目の選択、画面上の結果確認を1操作の証拠とする。
- 関数・変数・静的確認はUI検査後の補助情報であり、UI結果を上書きしない。
- UI操作と結果確認が未定義の項目はPASSにしない。
- README.md変更時以外は操作台帳を再生成しない。

## 残課題

直近の`docs/loop/current.json`でFAIL/ERRORの機能について、1件ずつUI操作と結果確認を実装し、同じループで再検査する。
