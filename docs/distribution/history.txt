QuickImageView Changelog
v4.2.0 (2026-09-21)
- Fixed HEIC/HEIF saving, which always failed in v4.1.0.
- A failed save no longer leaves an empty file behind, and an existing file is never touched.
- Save as now opens the file picker in the folder of the displayed image.
- A warning dialog now tells you when a save is refused because the file already exists.
- The Explorer right-click entry "Open with QuickImageView" now appears for every image type the application opens, including HEIC, HEIF, and WebP (it did not show on some PCs).
- Fixed the entry's icon, which showed a plain blank page. An entry from an earlier version is repaired automatically at the next start.

v4.1.0 (2026-09-21)
- Fixed a hang when moving the window between monitors with different display scaling.
- Default window size 720 x 480; File > Settings sets the window size.
- TIFF is written through WIC. Restored from 3.x: --convert, dark title bar, drop confirmation, reload after Save as, extension completion, HEIC/HEIF quality.
- Smaller distribution (native file dialogs, no unused plugins); built with MinGW.

v4.0.0 (2026-09-21) - withdrawn (hang when moving the window between monitors with different display scaling)
- Replaced the Win32 implementation with the Qt 6 (Qt Quick) implementation.
- Releases are an unsigned ZIP with SHA256SUMS.txt; the MSI installer was removed.
- WebP now uses Qt's WebP image-format plugin.

v3.1.3 (2026-09-20)
- Fixed build and release packaging after the folder restructure.

------------------------

2.1.0 (2026-08-24)
------------------

- Improved help readability and synchronized the application version.

Versioning rules
----------------

- First digit: new features
- Second digit: bug fixes
- Third digit: documentation and other changes

1.0.0 (2026-08-23)
------------------

- Added selection-only clipboard copy, overlay paste, and destination reload after Save As.
- Added dark information bars, Segoe UI, an application icon, and Japanese/English UI switching.
- Added MSI authoring with optional Explorer context menu and per-extension file associations.
