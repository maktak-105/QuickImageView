# QuickImageView 仕様書

[English version spec.md](spec.md)

QuickImageViewは、Qt 6（Qt Quick / QML）、C++17、Windows Imaging Component（WIC）、CMakeで構築するWindows向け画像ビューアー・編集アプリです。画像処理はGUIに依存しないC++へ分離しています。本書の対象バージョンは4.2.0です。

## 表示と操作

- コマンドライン引数、ファイルメニュー、`Ctrl+O`、ドラッグ＆ドロップで画像を開く。画像を表示中にドロップされた場合は、確認してから開く。
- ウィンドウへフィット表示し、マウスホイールで拡大・縮小、中ドラッグでパンする。
- 左ドラッグで矩形範囲を選択し、右クリックメニューから切り抜く。
- ファイル名、画像寸法、形式、ファイルサイズを表示する。EXIFが存在する場合は代表項目（メーカー、機種、撮影日時）を表示する。EXIFはフローティングウィンドウに表示し、テキストとしてコピーできる。EXIF・メタデータの編集は対象外。

## 編集

- 右90度、180度、左90度の回転、左右反転、上下反転。
- フルカラー、256色、グレースケールへの色変換。
- ユーザーが指定した正のパーセントまたはピクセル寸法でのリサイズ。縦横比の保持を選択できる。
- `Ctrl+Z` / `Ctrl+Y`によるUndo / Redo。
- `Ctrl+C`で画像または選択範囲をコピー。`Ctrl+V`で画像を貼り付ける。貼り付け画像は原寸のまま、貼り付け先の範囲内で移動でき、右クリックメニューで確定またはやり直しをする。

## 保存

- 「別形式で保存」は、先に保存オプションを表示し、その後にファイル選択へ進む。
- ファイル選択は、毎回、表示中の画像があるフォルダーで開く（保存した後は、保存先のファイルがあるフォルダー）。画像にファイルが無いときは、Windowsが決めたフォルダーで開く。
- 品質（JPEG・WebP・HEIC/HEIF、0〜100）と圧縮（PNGは0〜9、TIFFは0＝圧縮なし・1〜9＝LZW）はユーザー指定値で、固定候補に限定しない。
- 原本と既存の出力ファイルは上書きしない。この理由で保存を拒否したときは、モーダルの警告ダイアログに、理由、対処（別の名前または別のフォルダーで保存し直す）、ファイルのパスを表示する。状態テキストにも同じ趣旨のメッセージを残す。保存に失敗しても、作りかけのファイルは残さない。
- 保存形式: PNG、JPEG、BMP、TIFF、WebP、HEIC/HEIF。TIFFはWICで書く（Qtのプラグインは不要）。HEIC/HEIFはWindowsのHEIFエンコーダー（HEIF画像拡張機能とHEVCビデオ拡張機能）が必要で、無い場合は保存に失敗する。
- ファイル名に拡張子が無い場合は、選択した形式の拡張子を補う。
- 保存に成功したら、確認なしで保存先を読み込み直し、現在の画像として表示する。

## Windows連携

- ファイル > 設定から、Explorerの右クリックメニューへの登録・解除を行う（現在のユーザー、HKCU）。登録は、アプリが開く全ての画像（JPG、JPEG、PNG、TIF、TIFF、BMP、GIF、WebP、HEIC、HEIF、ICO、JXR、WDP、HDP、DDS）の拡張子ごとに行う。画像全体への1件の登録にしないのは、PCによっては、画像全体への登録がHEIC・HEIF・WebPのファイルにシェルで反映されないため。項目のアイコンは`QuickImageView.exe`に埋め込まれたものを使う（別のアイコンファイルは無い）。
- 起動時に、この実行ファイルを起動する登録を修復する。足りない拡張子の登録を追加し、古いアイコンの指定を書き直し、以前の版の「画像全体」への登録を消す。別の実行ファイルの登録には触れず、一度も登録していない場合は何も作らない。
- ファイル > 設定から、ウィンドウサイズ（内側の表示領域の幅と高さ、ピクセル。480×320〜7680×4320、既定は720×480）も指定する。値は`%LOCALAPPDATA%\maktak-105\QuickImageView\settings.ini`に保存し、次回の起動時に（プライマリ画面に収まる範囲で）使い、最大化中でなければ現在のウィンドウにも反映する。
- `scripts/install.ps1`は`%LOCALAPPDATA%`配下へユーザー単位でインストールし、`-NoRegisterContextMenu`を指定しない限り右クリックメニューへ登録する。

## コマンドライン

- `QuickImageView.exe --convert <変換元> <変換先>`は、ウィンドウを表示せずに画像を変換する。形式は変換先の拡張子で決まる。終了コードは成功が0、失敗が2（理由は`crash.log`へ書き込む）。原本と既存ファイルは上書きしない。

## UI

- ダークテーマ（タイトルバーを含む）、日英切替（メニュー、ダイアログ、情報、EXIF、ヘルプ）、アプリ内ヘルプ、バージョン・開発環境・制作者・作者ワッペンを表示するバージョン情報画面。

## 対応画像形式

- 開く: BMP、GIF、ICO、JPEG、JPEG XR、PNG、TIFF、Windows Media Photo、DDSはWICで読み込む。WebPはQtのWebP画像フォーマットプラグインで読み込む。HEICとHEIFは導入済みのWICコーデックで読み込む。
- 「画像を開く」ダイアログにはJPG/JPEG、PNG、TIFF、BMP、GIF、WebP、HEIC、HEIFを表示する。

## 対象外

- Explorerのサムネイル表示用シェル拡張
- フォルダー内画像の前後移動、スライドショー、印刷
- EXIF・メタデータの編集
- 画像の原本への直接保存

## テスト

CTestで`qiv_controller_tests`（Qt Test。GUI非依存のコントローラーとエンジン）と`qiv_qml_tests`（Qt Quick Test。オフスクリーン）を実行します。
