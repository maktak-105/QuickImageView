# QuickImageView Qt Quick移行 引継ぎ v3.0

作成日：2026-08-24  
ブランチ：`codex/qt-quick-migration`

## 現在の状態

Qt Quick版 `QuickImageViewQt.exe` の主要未実装機能を実装し、Win32版を維持したままビルド・CTest・Qt配布ZIP検査を完了した。`6.10.3/` は未追跡の重複Qt SDKであり、ユーザー指示により今回は放置する。

## 実装済み

- WIC画像読込、同梱WebP読込、PNG/JPEG/BMP/TIFF/WebP保存。
- JPEG/WebP品質、PNG/TIFF圧縮設定。
- 90度・180度・270度回転、左右・上下反転、色変換、数値リサイズ。
- 画像上の左ドラッグ切り抜き。
- クリップボード画像の仮配置・移動・範囲制限・確定・やり直し。
- WIC EXIF表示・コピー、EXIFなし表示。
- WIC HEIC/HEIF保存フォールバック。
- 画像ファイルのドラッグ＆ドロップ、コマンドライン画像起動。
- Undo/Redo、原本保護、既存出力上書き拒否。
- Qt診断ログと未処理Windows例外の`crash.log`。
- Qt版配布ZIP作成：`scripts/package.ps1 -Qt`。

## 検証済みコマンド

```powershell
git diff --check
.\build.bat
.\build.bat qt
```

CTest 3件はすべてPASS。Qt配布ZIPは`build/QuickImageViewQt-v3.1.2-win64.zip`に生成済み。

## 次の担当者が行う実機検証

1. EXIF付きJPEG fixtureでメーカー・機種・撮影日時・コピー結果を確認。
2. HEIC/HEIF WIC codecの有無を確認し、codecなし時に失敗理由が表示されることを確認。
3. 100%、150%、200%の高DPIで切り抜き・貼り付け・ダイアログの目視確認。
4. WindowsアクセシビリティツリーとTab/Enter/Esc操作を実機確認。
5. Qt版を正式配布対象へ切り替える場合は、関連付け・右クリック登録・インストーラーの実行ファイル名を一括更新する。
