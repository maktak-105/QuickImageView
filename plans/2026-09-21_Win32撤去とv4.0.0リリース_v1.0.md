# Win32撤去とv4.0.0リリース

## ユーザー指示（原文・2026-09-21）
Qt統合後の未決事項への回答:
1. 「撤去」（Win32ターゲット・tests/python・README のWin32前提の記述・installer/MSI）
2. 「既定をQt」（`scripts/build.bat` の既定ビルドをQtにする）
3. 「v4.0.0でリリース」
4. 「win32-legacyはpushしない」

## 前提
- 直前の作業でローカル `main` に `origin/qt` をマージ済み（fe09397、push なし）。
- Win32版は `win32-legacy`（897dcfa）にあり、リモートへは push しない。

## 実施内容
### 撤去（指示1）
- ソース: `src/app/main.cpp`・`resource.rc`・`resource.h`（Win32専用）。
- ビルド: `scripts/build.py`（Win32用）、CMake の Win32 ターゲット・`smoke_self_test`・libwebp（`third_party/` ごと）・`QUICKIMAGEVIEW_BUILD_QT` オプション。Qt は必須依存に変更。
- テスト: `tests/python/`（Win32 UI検査）、`tests/tools/`（スクリーンショット補助）。
- 配布: `installer/`（MSI）、リリースの MSI 工程。
- 資産: Win32 画面のスクリーンショット3点（`QuickImageView-gui-en/ja.png`、`qiv-drop-target.png`）。Qt版の画面ではないため README から外した。
- `.gitattributes`（`tests/python` の linguist 設定のみだった）。
- 文書: README・仕様・About・配布・環境・フォルダ構成・第三者ライセンス・配布用 readme を Qt 版の実態に書き換え。history に v4.0.0 を追加。
- 事実確認: WebP 読み込みは `QImageReader`、その他の読み込みは WIC、保存は `QImageWriter`（HEIC/HEIF は WIC へフォールバック）。`--convert` は Qt版に存在しない。

### 既定をQt（指示2）
- `scripts/build.bat` は `build_qt.py` を既定で実行。`qt` 引数は廃止。
- `build_qt.py` の対象から `QuickImageView`（Win32）を除外。
- 出力先を `dist/binary/` から `dist/` 直下へ（Quick テンプレート準拠）。`deploy_qt.py` は `dist/.gitkeep` を残す。
- `install.ps1` / `package.ps1` の `-Qt` スイッチを廃止（Qt のみ）。`install.ps1` は旧 `QuickImageView.exe` などの残骸を削除する。

### v4.0.0（指示3）
- 版数を CMake・ヘルプ・テスト・文書・AGENTS.md で 4.0.0 に統一。
- CI/Release のトリガーブランチを `main` のみに変更（`qt` を除外）。
- タグ push と GitHub Release の公開はユーザー指示（リリース）に基づき、コミット後に実施する。

### win32-legacy（指示4）
- `win32-legacy` は push しない（upstream 未設定のまま）。
