## ユーザー指示 2（原文・2026-09-21、置き換えの実施中に追加）
- 「Quickシリーズアプリで、どこにメールアドレスとかアカウント名が必要になるんだ？」
- 解釈: Quick シリーズのアプリで、メールアドレスや（Windows・GitHub の）アカウント名が、本当に必要になる場所はどこか、という質問。必要なものと、不要で消せるものを切り分けて答える。全プロジェクトの実物（追跡ファイル、テンプレートの規則、コミットの情報）で確認する。

## 解釈（確定ではない）
- 「全部」は、現在のコミット（HEAD）で追跡されているファイルに含まれる、Windows のアカウント名（2 種類）を含むパスの全件。置き換え先は `%USERPROFILE%` などの中立な表記にする。
- 実施しないこと: 履歴の書き換え（案 3。コミットの識別子が変わり、タグと Release が壊れる。指示されていない）、メールの設定（案 1。GitHub の設定と、ユーザーの Git 設定の変更で、ユーザー側の操作）。過去のコミットには、置き換え前の値が残る（これは、この対処では消えない）。
- 実施する場合の注意: `scripts/build.py` の既定の Qt のパスは、実際に動くコードの既定値。元の PC でも同じ場所を指すよう、ユーザーのホームフォルダーを基準にした書き方へ変え、動作を変えない。
- この計画書には、アカウント名やメールアドレスの実際の値は書かない。

3. 洗い出しを再実行して 0 件を確認する。ビルドとテストを実行し、コードの変更で壊れていないことを確認する。
4. コミットして `main` へ push し、CI の結果を確認する。
5. 履歴に残る分（過去のコミット、削除済みの `.pyc`）を報告する。

## 結果（QuickImageView の置き換え）
- 洗い出し: 追跡ファイル 15 件・28 行（`docs/environment.md`・`docs/environment_jp.md` 各 1 行、`scripts/build.py` 2 行、計画書 12 件 23 行）。すべて `Users\<アカウント名>\` の形のパスだった。
- 置き換え: 文書と計画書は `%USERPROFILE%` に置き換えた（区切り文字はそのまま）。`scripts/build.py` の Qt の既定パス 2 行は、`Path.home() / "tools" / "Qt" / …` に変えた。元の PC（ホームフォルダーが `C:\Users\<元のアカウント名>`）で、変更前のリテラルと**同じ場所**を指すことを、`PureWindowsPath` で確認した（2 つとも一致）。
- 再洗い出し: 追跡ファイルの該当は 0 件。差分は 28 行対 28 行で、行末コードの一括変換は無い。
- 検証: `scripts/build.py` の構文（`py_compile`）OK。環境変数を指定したフルビルド、CTest（コントローラー 39 件、QML 28 件）成功。環境変数なしでは、新しい既定のパスを示して「Qt CMake wrapper was not found」で止まる（この PC には既定の場所に Qt が無いため。変更前も同じ理由で止まる）。
- 過去のコミットには、置き換え前の値が残る（履歴の書き換えはしていない）。削除済みの `.pyc` 4 件（パスが埋め込み）も、履歴に残る。

## 「どこに必要か」の調査結果（ユーザー指示 2 への回答）
- 必要なのは「制作者名（= GitHub のユーザー名）」の表示だけ。共通テンプレートの規則: LICENSE は `Copyright (c) {{Year}} {{Author}} (GitHub: https://github.com/{{GitHubUser}})`、バージョン情報の制作者は「GitHubアカウントまたは制作者名」。使っている場所: LICENSE、`docs/about*.md`、バージョン情報画面、README・配布 readme の GitHub のリンク、実行ファイルの会社名（.rc）、`QGuiApplication::setOrganizationName`（設定・ログの保存先のフォルダー名 `%LOCALAPPDATA%\<ユーザー名>\<アプリ名>` とレジストリの場所を決める。変えると保存先が変わる）。
- メールアドレス: 全 9 プロジェクトの追跡ファイルに 0 件。どこにも必要ない。コミットの情報にだけ入る（Git が作者のメールを要求するため）。QuickDiskBench には、GitHub の noreply アドレスのコミットが 16 件あり、noreply で問題なく運用できている。他の 8 プロジェクトの全コミットは、個人のメール。
- Windows のアカウント名: どこにも必要ない。偶然入っただけ。QuickImageView 以外の追跡ファイル: QuickFolderSize（計画書 2 件、`proto/prototype/i18n.py`）、QuickFileCopy（計画書 2 件、`proto/prototype` のテストの例のパスと、ビルドのクラッシュレポート）、QuickMarkPDF（計画書 2 件）、Quick7Zip（計画書 1 件）、QuickDiskRescue（計画書 2 件）。製品のコードには無い。今回は QuickImageView のみ対処した。他は、ユーザーの指示待ち。
