# ウィンドウ移動時ハング調査

## ユーザー報告（原文・2026-09-21）
- 「起動してウインドウを動かすとハングアップする、これは公開できない」

## ユーザー追加指示（原文・2026-09-21、調査中に受信）
1. 「いますぐPrivateにして公開停止」
2. 「それから修復」
3. 「名前からQtを外してくれ、QuickImageView」（実行ファイル名などの `QuickImageViewQt` を `QuickImageView` に変更する）
4. 「ウィンドウサイズの縮小が制限されているが、これはなに？」（2026-09-21・次工程の確認への回答として受信。質問として調査・回答する。変更の指示はまだない）
   - 回答（原文選択）: 最小サイズは「小さめに緩和(例: 480x320)」、次工程は「Privateへpush→CI確認まで」。数値は選択肢の例のとおり 480x320 とする。
   - 調査結果: 制限は `src/ui/Main.qml:11-12` の `minimumWidth: 860` / `minimumHeight: 560`。ea8ed1e（2026-08-24、Qt版の最初の実装）で導入され、理由の記録なし。Win32 版に最小サイズ制限は無かった（`WM_GETMINMAXINFO` 処理なし）。

## 前提
- v4.0.0 は GitHub Release として公開済み（タグ v4.0.0、abb54a5）。ローカルの main は 27253c4（loop削除・フォルダ整理、未push）。
- 報告時にどのビルド（公開ZIP / ローカル dist）で発生したかは未確認。

## 調査方針
- 読み取りのみの調査から始め、原因をコードで特定してから修正する。
- 手動のEXE/UI操作はユーザー側で行う。自動化できる範囲（オフスクリーンのテスト・ログ）で再現・検証する。

## 調査結果
- `%LOCALAPPDATA%\maktak-105\QuickImageView\crash.log`（アプリが Qt の警告を記録する）に、`InfoWindow.qml:35`（x の binding）の「Binding loop detected」3,040 件と、`QWindowsWindow::setGeometry: Unable to set geometry` 約 3,000 件が記録されていた。情報ウィンドウが 2 台のモニター（`\.\DISPLAY1` と `LCD-AD223ED`、DPI が異なる）の間を行き来し続けていた。
- 原因: `InfoWindow` の `x` / `y` が、自分自身の `Screen` 添付プロパティと自分の実際の `width` に依存していた。配置により画面が変わる → Screen とサイズ（DPI で変わる）が変わる → 再配置、の無限ループになり、メッセージループが飢餓状態になってハングする。
- 再現（修正前ビルド）: 本体ウィンドウを `SetWindowPos`（マウス操作なし）で x=240 へ動かすとハング。350ms 足らずで `crash.log` が約 131KB 増加。
- 併発していた別の警告: 終了時に `TypeError: Cannot read property '...' of null`（appController が先に破棄される）。ハングとは無関係のため未対応。

## 実施内容
- `InfoWindow.qml`: 配置の入力を本体側の値だけにした。本体の画面の作業領域（`hostWorkAreaLeft/Top/Right`）を `Main.qml` から渡し、幅は固定の `preferredWidth`（440）で判定する。
- 回帰テスト `tests/qml/tst_infowindow.qml` を追加（5 件）: 右側に収まる場合の配置、収まらない場合の左回り込み、作業領域での下限、自分のサイズに依存しないこと、本体への追従。
- 名前変更（ユーザー指示3）: 実行ファイル・CMake ターゲット `QuickImageViewQt` → `QuickImageView`、`scripts/build_qt.py` → `build.py`、`deploy_qt.py` → `deploy.py`、`src/app/qt_resource.rc` → `QuickImageView.rc`、配布 ZIP をテンプレート規定の固定名 `QuickImageView-binary.zip`（従来 `QuickImageViewQt-<tag>-win64.zip`）。ソース内部のファイル名（`qt_main.cpp` など）は変更していない。
