# UI・貼り付け・保存フロー改善計画 v1.0

## 目的

QuickImageViewの情報表示を読みやすく統一し、範囲選択コピー、元画像へ重ねる貼り付け、保存先の再読み込みを実装する。

## 確定仕様

- 情報帯と操作メッセージは黒背景・白文字、アプリ内の表示フォントはWindows標準のSegoe UIとする。
- 選択枠の左上に、画像座標へ換算した選択サイズを`幅×高さ`で表示する。
- 選択中のコピーは選択範囲のみをクリップボードへ格納する。
- 貼り付けは元画像を置換せず、クリップボード画像を原寸で中央へ仮配置する。左ドラッグで画像範囲内に移動し、右クリックメニューの「OK」で確定、「やり直し」で移動を継続する。
- 保存成功時は元ファイルを変更せず、保存先ファイルを再読み込みして現在の表示へ切り替える。

## 検証

READMEの機能台帳を再生成し、各追加行の実UI操作と観測を`python/tests/ui_test.py`へ実装する。全件実装後に`python .\python\tests\run_loop.py`を実行する。
