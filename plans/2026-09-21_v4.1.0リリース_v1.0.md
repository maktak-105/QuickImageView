## 確認項目と結果
- Release 資産: `QuickImageView-binary.zip`（20,314,415 バイト = 19.4MB）と `SHA256SUMS.txt`。ダウンロードして SHA-256 が一致（6531664C…216A7A）。
- 展開した ZIP に `verify_package.ps1` を実行: 成功（123 ファイル・49.7MB。MinGW ランタイム 3 DLL あり、Svg・qtiff・qgif・qico・Dialogs・qmltypes・アイコンなし）。
- 公開された exe を、PATH が Windows のフォルダーだけの別プロセスで実行（自己完結の確認）:
  - 起動サイズ: 設定なしで 720×480。900×600 の設定は反映。10×10 は 480×320、99999×99999 は画面の作業領域（1536×816）、壊れた値は 480×320。`crash.log` の増加 0。
  - ウィンドウ移動の掃引（x=0〜2700、2 台のモニターの境界を含む）: 最後まで応答。v4.0.0 のハングは再現しない。`crash.log` は 15 件で、Binding loop は 0 件。DPI 切替時の `setGeometry` 警告のみ（増え続けない）。
  - ダークなタイトルバーの属性が、本体・情報ウィンドウの両方で 1（本体のタイトルは「QuickImageView 4.1.0」）。
  - `--convert`: bmp/tif/jpg で終了コード 0、既存先・同一パス・入力なしで 2、ウィンドウなし、失敗理由が `crash.log` に記録された。
- 検査の訂正: 最初の実行では、検査スクリプトが実行中に PATH へ Qt のパスを足しており（B・C も同じプロセスで PATH を引き継いだ）、自己完結の証明になっていなかった。PATH を変更しない版のスクリプトに替え、各検査を別プロセスで再実行して上記の結果を得た。
