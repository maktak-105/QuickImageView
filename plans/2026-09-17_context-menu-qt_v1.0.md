# Qt版右クリック登録の整合化 計画 v1.0

作成日: 2026-09-17

## 目的

Qt版を最新ビルドとして利用する場合に、ユーザー単位インストーラーが旧Win32実行ファイルを登録しないようにする。

## 実施内容

1. `scripts/install.ps1`へ`-Qt`を追加する。
2. Qt実行ファイル、Qt DLL、プラグイン、QMLランタイムをインストール先へ配置する。
3. 右クリック登録のコマンドを`QuickImageViewQt.exe`へ向ける。
4. 英日配布文書へ利用方法を追記する。

## 検証計画

- PowerShell構文解析とQtランタイム配置条件を確認する。
- `-Qt`指定で実配置し、レジストリのコマンドと`--self-test`を確認する。
- `git diff --check`、`build.bat`、`build.bat qt`を実行する。
