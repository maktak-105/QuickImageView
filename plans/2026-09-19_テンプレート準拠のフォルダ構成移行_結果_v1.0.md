# QuickImageView 標準フォルダ構成移行 実施結果 v1.0

実施日: 2026-09-19
対応する計画書: `plans/2026-09-19_テンプレート準拠のフォルダ構成移行_v1.0.md`

## 1. 実施内容

- Win32ソース・リソースを`src/app/`、静的UI素材を`src/ui/`へ移動。
- Python検査・補助コードを`tests/python/`・`tests/tools/`へ移動し、台帳、検査ランナー、カタログ再生成処理のパスを更新。
- ビルド入口を`scripts/`へ移動。CMake中間生成物とZIP/MSI stagingは`build/intermediate/`、EXE/MSIは`dist/`直下へ統一。
- 開発・配布文書を`docs/`・`docs/distribution/`へ移動し、README、環境、仕様、検査引継ぎの参照と手順を現行配置へ更新。
- GitHub Release WorkflowにZIP・EXEのSHA-256生成と`SHA256SUMS.txt`添付を追加。
- 旧`dist/binary/`に残っていたQt配布物と旧ビルドツリーを`build/intermediate/legacy-qt-package/`・`legacy-qt-build/`へ移動して保全。

## 2. 検証結果

- `python scripts/build.py`成功。実行ファイルは`dist/QuickImageView.exe`へ出力。
- 旧パスは現在のコード・README・docs・ワークフローから除去。過去のplansおよび検査レポートは履歴資料として保持。
- `git diff --check`で空白エラーなし。
- CTestおよび統合UI検査は未実施。
