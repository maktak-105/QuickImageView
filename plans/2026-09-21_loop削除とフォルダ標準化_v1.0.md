# loop削除とフォルダ標準化

## ユーザー指示（原文・2026-09-21）
- 「loopは失敗してるので全て削除して、標準に準拠していないフォルダも整理してqml、build-toolsとか」

## 前提
- v4.0.0 をリリース済み（タグ v4.0.0、main は c7cee3a）。
- 標準 = Quickシリーズのアプリテンプレート `___appli-template`（2026-09-18 刷新版の `01_フォルダ構成.md`）。`src/{app,cli,engine,ui}`、`scripts/`、`docs/`（`docs/distribution/`）、`plans/`、`assets/`、`dist/`（直下・Git管理外）、`build/intermediate/`、`tests/`、`third_party/`、`HISTORY.md`。
- メモリ上のテンプレート記述（`core/native/`、`dist/binary/`、`document/`）は 32 日前のもので、現行テンプレートと異なるため現物を参照した。

## 調査結果（実物確認）
- loop 系（追跡）: `.agents/`（loop オーケストレーターのスキルのみ、23 ファイル）、`docs/loop/`（36 ファイル）。
- loop 系（ローカル・Git管理外）: `skills/`（loop の pycache のみ）、`docs/loop/.locks/`。pre-commit フックは前作業で撤去済み。
- 標準外: `qml/`（テンプレートでは UI ソースは `src/ui/`）、`build-tools/`（pycache のみ）、`installer/`（graphify キャッシュのみ。MSI 撤去済み）、ルートの `HISTORY` が小文字（`history.md`）。
- 重複 SDK: リポジトリ内 `6.10.3/`（9,995 ファイル・約1.18GB）は `C:\Qt\6.10.3` と主要ファイルの MD5 が一致（Qt6Core.dll、windeployqt.exe、Qt6Config.cmake、qwebp.dll）。ビルドは `C:\Qt` を使用。`.gitignore` のコメントも重複と明記。`aqtinstall.log` はその導入ログ。

## 実施内容
- 削除（追跡）: `.agents/`、`docs/loop/`。
- 削除（ローカル）: `skills/`、`build-tools/`、`installer/`、`6.10.3/`、`aqtinstall.log`。
- 移動: `qml/` → `src/ui/`（`git mv`）。CMake の `QML_FILES`、`deploy_qt.py` の `--qmldir` を追随。
- 改名: `history.md` / `history_jp.md` → `HISTORY.md` / `HISTORY_jp.md`（テンプレート準拠）。README の参照を更新。
- `.gitignore`: 重複 SDK・loop のロック・installer の各行を削除。ユーザーの未コミット変更 `graphify-out/` は維持。
- 文書: `docs/project-structure.md` を現行構成へ書き換え。`AGENTS.md` の古い記述（`build.bat qt`、`qml/`、「Qt移行後」）を修正。
- 残置（意図的）: `.venv/`（標準の除外対象）、`.claude/`、`graphify-out/`（ユーザーのツール出力・Git管理外）、`build/`、`dist/`、`plans/` 内の過去の計画書（履歴のため）。

## 確認項目
- ビルドと CTest、`package.ps1`、`install.ps1`（一時フォルダー）の結果は結果ファイルに記録する。
