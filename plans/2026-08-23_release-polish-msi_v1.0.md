# リリース整備・日英UI・MSI 計画書 v1.0

作成日: 2026-08-23  
対象バージョン: v1.0.0

## 1. 目的・背景

QuickImageViewを配布可能なWindowsアプリとして整え、統一テーマ、アプリアイコン、日英表示切替、利用者向けヘルプと開発文書、libwebpの再配布表示、MSIインストーラーを用意する。

## 2. 現状

Win32/WICアプリとして主要な画像操作は実装済みだが、表示言語は固定、アイコンと実行ファイルのバージョン情報は未整備である。PowerShellによる簡易インストールはあるが、MSIは未作成である。

## 3. 変更方針

- ダークテーマとWindows標準Segoe UIを維持し、右上の言語ボタンで日本語・英語を切り替える。
- 実行時生成アイコンとRCのバージョン情報を追加する。
- Quickテンプレートに合わせて日英のREADME、配布文書、履歴、仕様、環境、第三者ライセンスを同期する。
- WiX Toolset v3のMSI定義を追加する。コンテキストメニューと拡張子関連付けはインストーラーの選択機能とし、既定では有効にしない。

## 4. 変更対象ファイル

| ファイル | 変更内容 |
| --- | --- |
| `core/native/main.cpp` | テーマ、アイコン、日英切替UI |
| `core/native/resource.rc` | 実行ファイルのバージョン情報 |
| `installer/` | WiX MSI定義とビルドスクリプト |
| `document/`, `dist/documents/`, README、HISTORY | 日英文書・ヘルプ・ライセンス整備 |

## 5. 検証方法

Releaseビルド、自己テスト、起動スモークテスト、日英切替の実UI確認、MSIの生成と展開内容の確認を行う。
