# 右クリックの重複登録整理 計画 v1.0

作成日: 2026-09-17

## 目的

同一製品の旧実行ファイル登録が画像・文書の「アプリで開く」に重複して表示される状態を整理する。

## 対象と方針

- ユーザー単位の`FileExts\\*\\OpenWithList`を確認する。
- 同一製品の旧実行ファイルが現行実行ファイルと重複する場合だけ、旧名を現行名へ置換する。
- 実体が存在しない旧実行ファイルは、同一製品の現行登録が存在する場合に限り削除する。
- 他社アプリの有効な登録、画像ファイル、既定アプリの`UserChoice`は変更しない。
- Windows 11のモダン／従来Shell拡張の二重表示が確認された場合は、ユーザー単位の従来メニュー統一を可逆設定として使用する。

## 検証計画

- 全拡張子の`OpenWithList`で同一アプリの同一拡張子内重複がないことを確認する。
- Explorerを再起動し、シェルのキャッシュを再読み込みさせる。
