# ループ001 実施記録

## 対象

画像ファイルを1枚開いて、Windowsウィンドウ内へ表示する。

## 役割

- メイン担当: プロジェクト骨格、実装、ビルド、統合
- Locke（環境・ビルド担当）: 利用可能なツールチェーンと依存物の確認
- Dirac（設計レビュー担当）: 初回ループの構成とテスト観点のレビュー

## 実装

- C++17 + Win32 + Windows Imaging Component（WIC）を採用。
- CMakeでMinGW Makefiles向けのビルド定義を作成。
- コマンドライン引数の画像パスを読み込む。
- WICで画像を32bpp PBGRAへ変換する。
- ウィンドウ内にアスペクト比を維持して中央フィット表示する。
- `--self-test` による非対話スモークテストを追加。
- 原本ファイルへの書き込み処理は実装していない。

## 検証

- CMake configure: 成功
- CMake build: 成功
- CTest: 1件成功
- 実画像を指定した起動スモークテスト: プロセス起動を確認

## レビュー修正

初期の `--help` テストはメッセージボックスを表示するため自動テストが対話待ちになった。対象プロセスをPID指定で終了し、`--self-test` に置き換えた。

## 次ループ

1. ズームと右ドラッグによるパン。
2. 画像なし起動時の空状態画面。
3. Unicodeパス・破損ファイル・対応外形式のエラー表示。
4. WICで実際に読み込める形式を計測し、表示対応形式と性能上限を記録する。
