# TIFF保存のWIC対応

## ユーザー指示（原文・2026-09-21）
- 「意味が解らない、qtiffが入らない可能性がある？入れればいいじゃないか」
  - 直前の説明（CI の MinGW 化）に対する反応。TIFF 保存がビルドによって使えない可能性を残さず、確実に動くようにしてほしい、という趣旨と解釈する。

## 背景（実測済みの事実）
- ローカルの MinGW 版 Qt には `qtiff.dll` が無く、`QImageWriter` は TIFF を書けない（「Unsupported image format」）。
- CI（MSVC 版 Qt）の公開 ZIP には `qtiff.dll` が入っており、TIFF 保存は動く見込み。
- つまり TIFF 保存の可否が Qt のビルドに依存している。MSVC 版の `qtiff.dll` を MinGW のアプリへ入れることはできない（コンパイラの ABI が異なる）。
- 既に HEIC/HEIF の保存は、Qt が書けない場合に Windows Imaging Component（WIC）で保存する作りになっている（`saveHeifWithWic`）。WIC は TIFF のエンコーダーを標準で持つ。

## 方針
- TIFF の保存を WIC で行い、Qt のプラグインに依存しないようにする。どのビルドでも同じ動作になる。
