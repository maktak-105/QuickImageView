# QuickImageView 現行ビルド仕様書

## 1. ユーザー指示による開発方針

このリポジトリを確認して現状を把握する。破綻した既存ループは引き継がず、スクラッチでループ設計を作り直す。ゴールは明確に定義し、テストプログラムで検査可能にする。

- 過去ログ、過去の言い訳、ループ結果ログは保存・判定に使わない。
- 思い付きで要求を追加しない。ユーザーが指示した機能、指摘、操作、対象外だけを管理対象にする。
- 仕様書、チェックリスト、静的HTMLダッシュボード、管理ループを先に完成させる。
- それらが完成するまでアプリ本体の改修を進めない。
- 静的検査と動的検査を全機能に対して実施し、検査できない項目は未完了として扱う。
- 管理者は要求、実装、検査、進捗をチェックリストで管理し、未検査の機能を完了扱いにしない。

## 2. 仕様書の扱い

この文書は、現行ビルドを合格判定するための要求仕様です。必須項目を満たさないビルドは未完成です。判定は `python .\python\tests\run_loop.py` の終了コードと生成済みダッシュボードで行います。

- `0`: 仕様・検査・ビルド・インストール版検査がすべて合格
- `1`: 未達、回帰、検査不足、または手動確認待ち
- 過去ログ、結果ログ、スクリーンショット、口頭説明は合格根拠にしない

## 3. 必須機能

### 表示と操作

- コマンドラインまたはファイルメニューから画像を開いて表示する。
- フィット表示、ズーム、パンを行う。
- ファイル名、画像寸法、形式、ファイルサイズを表示する。
- EXIFが存在する画像では、メーカー、機種、撮影日時など代表項目を表示する。
- 左ドラッグで選択範囲を作成し、その範囲を切り抜く。中ドラッグはパンに使う。
- パン、拡大縮小、範囲選択中に画像が点滅して見えないよう、滑らかに描画する。

### 編集

- 固定プリセットに限定せず、ユーザーが指定した正のパーセントまたはピクセル寸法でリサイズする。
- リサイズにはアスペクト比固定オプションを設け、初期状態はONにする。
- 90度、180度、270度回転、左右ミラー反転（Mirror）、上下反転。
- Ctrl+Z / Ctrl+Y によるUndo / Redo。Undo / Redoはメニュー項目に表示しない。
- Windowsクリップボードへの画像コピーと、クリップボード画像の貼り付け。

### 保存・変換

- 原本を変更せず、別ファイルへ保存・変換する。
- 「名前を付けて保存」は、いきなり保存先フォルダ選択へ進まず、先に保存オプションを表示する。
- 保存オプションで形式、JPEG品質、PNG圧縮、WebP/HEIC/HEIF品質などを指定してから保存先を選ぶ。
- JPG、PNG、TIFF、BMP、GIF、WebP、HEIC/HEIFを扱う。後者は利用可能なWindows WICコーデックが必要。
- ユーザーが指定したJPEG品質、PNG圧縮、WebP/HEIC/HEIF品質などの設定を適用する。品質値を固定候補に限定しない。
- フルカラー、256色、グレースケールへ色変換する。
- 同一パスへの保存、既存出力ファイルの上書きを拒否する。

### Windows連携

- インストール版をExplorerの画像右クリックメニューから起動できるよう登録する。
- 登録コマンドと実行ファイルの一致は自動検査する。
- 実際のExplorer画面での右クリック操作は別の手動確認項目とし、確認なしに合格としない。

### UI・配布・安全性

- 情報帯と下部メッセージは黒背景・白文字で表示する。
- アプリ全体、タイトルバー、メニュー、ダイアログ、EXIF、ヘルプをダークテーマにする。
- Windows標準のSegoe UIを使用し、専用フォントをインストールしない。
- 日英切替でメニュー、ダイアログ、情報帯、EXIF、ヘルプの表示言語を切り替える。
- EXIF情報は画像に重ならないフローティングウィンドウで表示し、Unicodeテキストとしてコピーできる。
- 貼り付け画像は原寸のオーバーレイとして移動し、移動範囲を元画像内に制限する。右クリックのOKで確定し、やり直しで移動を継続する。
- 変換成功後は確認なしで保存先を再読み込みし、原本を変更しない。
- MSIには実行ファイル、日英ヘルプ・文書・履歴、MIT License、libwebpのCOPYING/PATENTSを同梱する。
- MSIの右クリック登録と各画像拡張子関連付けは独立した任意選択で、既定では関連付けを選択しない。

## 4. 明示的な対象外

## 対応画像形式

Windows Imaging Component（WIC）の対応デコーダーが利用できる場合、BMP、GIF、ICO、JPEG、JPEG XR、PNG、TIFF、Windows Media Photo、DDS、WebP、HEIC、HEIFを開けます。BMP、GIF、ICO、JPEG、JPEG XR、PNG、TIFF、Windows Media Photo、DDSはWindows標準WICで扱えます。WebPとHEIF/HEICは追加コーデックの導入状況に依存します。現在の「画像を開く」ダイアログにはJPG/JPEG、PNG、TIFF、BMP、GIF、WebP、HEIC、HEIFを表示します。

- Explorerのサムネイル表示シェル拡張。
- フォルダ内画像の前後移動、スライドショー、印刷。
- EXIF・メタデータの編集。
- 過去ログ、ループ結果ログ、言い訳・履歴の保存。

## 5. 回帰維持契約

新機能追加やUI変更によって、ファイル情報、EXIF表示、原本保護、Explorer登録の安全性を削除・破壊してはなりません。維持契約は `docs/loop/invariants.json` に定義し、契約変更にはユーザーの明示承認が必要です。

## 6. 検査方法

管理ループは、仕様・チェックリストの整合性、静的回帰、クリーンビルド、CTest、実データ編集・変換、ビルド版UI、一時インストール、SHA-256一致、インストール版UI、チェックリスト網羅性を順に検査します。1項目でもFAILなら未完成です。

完了判定:

```powershell
python .\python\tests\run_loop.py
```

ダッシュボード生成:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\python\tests\generate_dashboard.ps1
```

正本は `docs/loop/goal.json`、`docs/loop/invariants.json`、`docs/loop/checklist.json` です。
